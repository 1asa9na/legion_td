# План

Заметки обновляются вместе с шагом. Архитектура и деплой — в [ARCHITECTURE.md](ARCHITECTURE.md).

Карта — Legion TD War v1.50c (Lisk). Исходник карты в git не входит: `war3map*` лежит рядом и закрыт `.gitignore`. Каталог снят с редакторской версии с legiontd.com и сверен со списком продажи из локальной карты.

## 0. Деплой каркаса — сделано

`https://legion.bgylke8.online` открывается из меню бота. Страница — пустая полоса и строка «Каркас». `/health` отвечает `{"ok":true}`. Образы собираются в GitHub Actions и подтягиваются на сервер из GHCR.

## 1. Каталог — сделано

`@legion/content` описывает расу Mech и 30 волн плюс бонус. Числа из триггеров `Setup Tower Properties`, `Setup Tower Types`, `Setup Creep Properties`, объектов `war3map.w3u` и таблицы брони `war3mapMisc.txt`. Имена из `war3map.wts`.

Одноразовый читатель — `tools/extract-catalog.py`. В рантайме его нет.

Продажа — `R2I(стоимость × 0.50)`, дробная часть отбрасывается. У Doomsday Machine в списке продажи 850, а сумма золота по цепочке (Neotank 360 + свои 450) равна 810. В каталоге оставлено 850: возврат считает список.

Клиент каталог не рисует. Деплой этого шага картинку в Telegram не меняет.

## 2. Симуляция — сделано

`@legion/sim` считает матч сам, без Pixi и Colyseus. Тик 100 мс. Состояние — обычный объект. Команды `build`, `upgrade`, `sell` применяются в начале тика.

Линия — ломаная левого игрока: центр спавна `gg_rct_1` (-5696, 6080), низ коридора (-5696, 2784), центр `LNoBounty` (-3536, 2256), король (-3520, -3264). Клетки стройки — 12 по 64 вдоль пути, север слева по ходу.

Старт матча: золото 100, доход 0, первый таймер 90 с из `Start Game`. Следующие подготовки берутся из таблицы волны, 35 + уровень. Волна появляется целиком и две секунды стоит, потом идёт со своей `moveSpeed`. Краб — 225.

Боец есть только у башни, которая стояла к началу раунда. Постройка в бою молчит до следующей волны. Боец и король не ходят. Крип останавливается, когда его оружие достаёт бойца или короля, и с линии не сходит. На ходу крипы раздвигаются на сумму столкновений. Удар достаёт на радиус оружия плюс столкновение цели.

Урон — среднее мин/макс, затем таблица типа атаки и кривая брони Warcraft III (0.06). Кости не кидаются, полёт снаряда не считается. Хаос не различает типы брони. Заклинания игнорируют число брони.

Король — `h00K`, 2600 здоровья, броня героя 5 (карта число не задаёт, остаётся броня сторожевой башни), атака героя 31–41, перезарядка 0.9, радиус 715. Он стреляет сам. Его смерть кончает матч до золота за волну. Одинокий краб умирает на подходе. Пачка из двенадцати успевает дойти хвостом: король бьёт одного раз в 0.9 с, и восемь крабов наносят по одному удару.

Убийство сразу платит `bounty`. Крип, вошедший в `LNoBounty`, награды не даёт, кроме волны из одного юнита. Конец раунда добавляет `endRoundGold` и накопленный доход. Доход начинается с 0 и от стройки не растёт.

Продажа только между раундами. Свежая башня возвращает `value` из списка, после раунда — `sellGold`. У Doomsday Machine это 850 и 425.

Не считается: сетка путей Warcraft, время полёта снаряда, способности, сенд, воздух, еда. Столкновение бойца и короля — запасные 16, в объекте поле пустое.

Тесты: броня, краб, продажа Peewee и Doomsday, ворота без награды, удар короля, волна из одного крипа. Клиент этот шаг не рисует.

## 3. Комната — сделано

`PingRoom` заменена комнатой `match`. Сервер вызывает `step` каждые 100 мс и шлёт снимок `state`. Команды `build`, `upgrade` и `sell` ждут следующего тика. `race` принимает только `mech`. `send` отвечает `unsupported`: отправки крипов в симуляции ещё нет.

Вход проверяет Telegram `initData`. Подпись — HMAC от `BOT_TOKEN`, срок `auth_date` — сутки. Без подписи, без пользователя или из браузера место не резервируется. У каждого входа свой матч на одного игрока. Выход закрывает комнату.

Клиент из бота входит в комнату. Линию по снимку он ещё не рисует.

Тесты: подпись initData, очередь команд на тике, отказ браузеру и постройка Peewee через сокет.

## 4. Клиент

Рисунок и кнопки — в [CLIENT.md](CLIENT.md). Pixi показывает ломаную левой линии, клетки у спавна, крипов и короля по снимку `state`. Сводка: золото, доход, номер волны, таймер подготовки или здоровье короля. Снизу базовые башни Mech, апгрейд и продажа. Команды те же, что уже принимает комната: `build`, `upgrade`, `sell`.

Первая подготовка остаётся 90 с. Браузер без `initData` в матч не входит. Сенд, другие расы и второй игрок в этот шаг не входят. Клиент симуляцию не запускает.

## 5. Играбельный срез

Один игрок против волн, раса Mech, волны доходят до короля. Это первая сборка, в которую можно зайти из Telegram и доиграть линию. Мультиплеер, сенд и остальные расы сюда не входят.

## 6. Матч

Дальше по слоям, каждый можно выкатить отдельно: 1v1 со сендом, затем 4v4 с двумя королями и общим путём волны, затем остальные расы, бонусный уровень и режимы AP / AR / NI.
